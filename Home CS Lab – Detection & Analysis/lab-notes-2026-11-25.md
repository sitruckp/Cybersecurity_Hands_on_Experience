## 2. Hardening – Changing Wazuh Admin Password (Docker)

### Problem
Wazuh Dashboard rejected password changes with:
```
Failed to reset password. {"status":"FORBIDDEN","message":"Resource 'admin' is reserved."}
```
The `admin` user is reserved in OpenSearch Security and cannot be changed from the UI.

### Solution (Docker-specific)
Because the stack runs in Docker (`single-node-wazuh.*` containers, version 4.14.9):

1. Generated a bcrypt hash of the new password using the official indexer image.
2. Updated the hash in  
   `/home/kevin/wazuh-docker/single-node/config/wazuh_indexer/internal_users.yml`
3. Updated `INDEXER_PASSWORD` in `docker-compose.yml` (avoided `$` characters that break Compose variable substitution).
4. Recreated the indexer container and applied the config with:
   ```bash
   securityadmin.sh -cd .../opensearch-security/ ...
   ```
5. Restarted the stack.

**Lesson learned:** Password changes on a Docker Wazuh install require both host file edits **and** an explicit `securityadmin.sh` run inside the indexer container. The bare-metal password tool does not work.

## 3. Wazuh Agent Installation on labserver

### Goal
Install the Wazuh agent on the same host that runs the manager so the server reports its own telemetry.

### Steps performed
1. Added the official Wazuh APT repository (GPG key + sources list).
2. Installed `wazuh-agent` package (version **4.14.11**).
3. Configured the agent to point at the manager:
   ```bash
   sudo sed -i 's/MANAGER_IP/192.168.0.199/' /var/ossec/etc/ossec.conf
   ```
4. Enabled and started the service.

### Result
```
ID: 013, Name: labserver, IP: any, Active
```
Service status: `active (running)`.

**Portfolio note:** Shows ability to install and register an agent against a Docker-hosted manager on the same host.
